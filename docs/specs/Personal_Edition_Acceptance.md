# Beta 发布验收（Mac + Chrome）

适用：macOS 15+ Apple Silicon、本地/ad-hoc 签名、Chrome 开发者模式。此清单是待执行标准，不代表已全部通过。

## 自动检查

1. Rust 分区迁移、跨分区约束、失效预览拒绝、同步快照重建通过。
2. OVB 主密码/恢复密钥恢复、篡改拒绝、本地恢复点、安全重建和改密崩溃恢复通过。
3. Release 即使设置开发绕过标志也必须校验 IPC 对端。
4. Flutter 分析无 error/warning，发布构建成功；已有 info 风格建议单独统计，不通过全局关闭规则掩盖。
5. App 包含 native-host、askpass、expect 脚本和插件资源；CLI 独立下载且版本可查。
6. 三个归档可解包、SHA-256 校验通过，Git 提交可追溯。

## 真机手工检查

- [ ] 干净机器从下载包安装，无仓库、Rust/Flutter 环境或旧辅助文件也可启动。
- [ ] 新建库，主密码和本机验证解锁；重启、锁屏、睡眠和空闲锁定符合配置，锁定期间不泄露缓存。
- [ ] App 放入 Applications 后 Chrome 可连接；更新 Native Host 后重试可恢复，不把重启浏览器作为日常修复。
- [ ] 至少一个真实网站完成密码保存、更新、填充、MFA，导航/取消后请求失效。
- [ ] SSH 签名和服务器一键连接在无开发环境的机器可用，拒绝与取消不会发放秘密。
- [ ] 分区、分组、折叠、筛选、迁移和回收站正常，关联记录一起迁移。
- [ ] OVB 在另一空目录分别以主密码和恢复密钥恢复，核对凭据、历史、分组和关联。
- [ ] 两台设备用测试 WebDAV 目录演练首次三种策略、同条记录冲突、断网重试与历史保留；不操作生产目录。
- [ ] 通行密钥预览完成目标站点注册和登录，不支持的请求可回退浏览器。
- [ ] 最低和最新系统完成覆盖升级；大字体、窄窗口、键盘和 VoiceOver 不泄露秘密。

## 分发说明

App、CLI、Chrome 扩展分别下载。无公证 Beta 必须说明安装限制；S3 和通行密钥兼容范围如实标注。公开后升级不能默认清空远端。Apple Developer ID 签名与公证未执行时，不得将本地签名校验等同公证验收。
